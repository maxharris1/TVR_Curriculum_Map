# Transfr Data Explorer

## Development

To run this project locally:

1. Ensure you have Node.js & npm installed ([install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).
2. Clone the repository: `git clone <YOUR_GIT_URL>`
3. Navigate to the project directory: `cd <YOUR_PROJECT_NAME>`
4. Install dependencies: `npm i` (or `bun install` if using Bun)
5. Start the development server: `npm run dev` (or `bun run dev`)

## Technologies

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
